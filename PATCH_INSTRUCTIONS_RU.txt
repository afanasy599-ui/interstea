ПАТЧ INTERSTELLAR EXPERIENCE 0.4.0

Распакуйте архив прямо в корень репозитория GitHub и согласитесь на замену файлов.
Папка .github скрытая — проверьте, что она тоже обновилась.

Файлы патча:
- TesseractScreen.java — выводит новую полноэкранную сцену вместо старого HUD.
- TesseractSceneRenderer.java — программно строит перспективный 3D-коридор, летающего блочного астронавта и объёмные фрагменты мира.
- gradle.properties / fabric.mod.json / build.yml — версия 0.4.0 и имя артефакта.

После загрузки изменений нажмите Commit changes и откройте Actions.
Скачайте artifact InterstellarExperience-Fabric-1.21.11-v0.4.0.
Перед установкой удалите старый JAR версии 0.3.0 из .minecraft/mods.

Сборку Gradle версии 0.4.0 нужно подтвердить GitHub Actions — в этом окружении нет сетевого доступа для запуска полного Gradle build.
