# Interstellar Experience 0.4.0

Клиентский Fabric-мод для Minecraft Java 1.21.11. Версия 0.4.0 заменяет прежний экран с плоскими карточками на полноэкранную кинематографическую 3D-сцену.

## Что теперь происходит при открытии Тессеракта

- Камера смотрит внутрь уходящего в перспективу пространственного коридора с повторяющимися металлическими рамами и световыми направляющими.
- Перед камерой медленно дрейфует и вращается блочный астронавт.
- Вокруг него и в глубине коридора парят объёмные фрагменты ближайшего Minecraft-мира. Это не карточки: каждый фрагмент собирается из небольших трёхмерных блоков, взятых из клиентского снимка мира.
- На дальнем плане видна Гаргантюа с аккреционным кольцом.
- При открытии запускается голосовая фраза; её можно повторить клавишей R.

## Управление

| Клавиша | Действие |
|---|---|
| `O` | Открыть / закрыть сцену |
| `P` | Сохранить текущий момент мира |
| `←` / `→` или `A` / `D` | Переключить выбранный временной снимок |
| `R` | Повторить голосовую фразу |
| `Esc` | Закрыть сцену |

История автоматически записывает снимок примерно каждые 10 секунд и хранит до 9 последних снимков. Клавиша `P` позволяет сохранить дополнительный момент вручную.

## Что именно копируется из мира

Мод работает только с чанками, которые уже доступны клиенту. Для каждого снимка он запоминает локальный объём 17×17×12 блоков вокруг игрока и цветовые значения блоков для построения объёмного эха. Сцена не загружает неоткрытые сервером чанки и не меняет мир.

## Честные ограничения версии 0.4.0

- Астронавт пока стилизованный блочный персонаж в скафандре, а не точная копия текущего скина игрока.
- Цвета блоков основаны на цветах карты Minecraft; это объёмная визуализация ландшафта, а не полное текстурированное воспроизведение каждого блока.
- История начинает записываться после загрузки мода. Прошлые действия до этого момента восстановить нельзя.
- Движения мобов, игроков, содержимое сундуков и редстоун-состояния пока не записываются.
- Это клиентская кинематографическая сцена. Серверу не требуется устанавливать мод, но эффекты видны только на клиенте.

## Установка

1. Установить Minecraft Java 1.21.11, Fabric Loader и Fabric API.
2. Удалить старые JAR-файлы `interstellar-experience` из папки `mods`.
3. Скопировать собранный `interstellar-experience-0.4.0.jar` в `.minecraft/mods`.
4. Запустить игру с профилем Fabric 1.21.11.
5. В одиночном мире или на сервере нажать `O`.

## Сборка через GitHub Actions

В репозитории уже лежит workflow `.github/workflows/build.yml`. После загрузки исходников в ветку `main` GitHub Actions выполнит `gradle build` и приложит JAR как артефакт.
