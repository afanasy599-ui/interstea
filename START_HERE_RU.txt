НОВЫЙ РЕПОЗИТОРИЙ INTERSTELLAR EXPERIENCE 0.2.0

1. На GitHub нажмите New repository.
2. Название: interstellar-experience
3. Выберите Public или Private.
4. НЕ ставьте галочки Add a README, .gitignore или License — эти файлы уже есть в архиве.
5. Создайте репозиторий.
6. Распакуйте этот ZIP на компьютере. Важно: загружайте СОДЕРЖИМОЕ архива в корень репозитория, а не папку-обёртку.
7. На странице пустого репозитория выберите uploading an existing file. Перетащите все файлы и папки из распакованного проекта, включая скрытую папку .github.
8. Нажмите Commit changes. В качестве ветки используйте main.
9. Откройте Actions и проверьте workflow Build Interstellar Experience. Он также запускается автоматически после push в main.
10. После успешной сборки откройте запуск Actions и скачайте artifact InterstellarExperience-Fabric-1.21.11-v0.2.0.

ВАЖНО: это чистый новый репозиторий, старый interstellar не удаляйте. Сборка ещё должна быть подтверждена GitHub Actions — заранее считать её успешной нельзя.

Мод версии 0.2.0 — клиентский визуальный прототип. Он записывает небольшие цветовые снимки загруженной рядом с игроком поверхности и показывает их в интерфейсе Тессеракта. Это не полная 3D-копия мира и не запись всех действий игроков/мобов.
